## V1 coverage

No symbols are currently included. All 36 curriculum entries deliberately use the app's text-only answer fallback rather than an unrelated or semantically ambiguous picture. Suitable Mulberry SVGs can be added here later and mapped explicitly in `src/apps/reading/readingWords.ts`.
